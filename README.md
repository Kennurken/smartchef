# SmartChef · учебная лабораторная №6
Локальное демо, реконструированное по контракту №5. Никаких production данных.
По умолчанию включены явно обозначенные фикстуры; Gemini не вызывается.
Python 3.12/3.13, Django 6.0.x. Демо проверяется на Python 3.13.
Создай .venv, установи requirements.txt, скопируй .env.example в .env,
выполни python manage.py migrate и python manage.py runserver.
Для готовки нужен solution; starter воспроизводит исходный текстовый формат.
См. полный двуязычный урок и отчёт в соседней папке docs.
