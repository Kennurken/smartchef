# SmartChef · Зертханалық жұмыс №6 (Режим готовки и основы GitHub)

SmartChef — өнімдерді таңдап, рецепт генерациялайтын, базаға (`SavedRecipe`) сақтайтын және тексерілген құрылымды рецепттер үшін қадамдық **Дайындау режимін (Cooking Mode)** ашатын Django қосымшасы.

## Режим работы (Demo / Live)
- Әдепкі бойынша оқу фикстурасы режимі қосылған (`SMARTCHEF_DEMO=1`). Бұл режимде `recipes/provider.py` детерминирленген JSON фикстура қайтарады (Gemini/Groq API шақырылмайды) және `valid`, `invalid`, `empty`, `error` сценарийлерін тексеруге мүмкіндік береді.
- Нақты провайдермен жұмыс істеу үшін `.env` ішінде `SMARTCHEF_DEMO=0` және API кілтін орнату жеткілікті.

## Іске қосу
```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
python manage.py migrate
python manage.py runserver
```
